## 📋 配置步骤

### 步骤 1：登录腾讯云

1. 访问：https://cloud.tencent.com/
2. 使用子账号登录：
   - 用户名：shijitong
   - 密码：Jx9I,)DG

### 步骤 2：获取访问密钥

1. 点击右上角头像
2. 选择「访问密钥」
3. 查看现有密钥或新建密钥
4. 复制以下两个值：
   - **SecretId**（类似 `AKIDxxxxx`）
   - **SecretKey**（类似 `xxxxx`，32 位）

### 步骤 3：配置到微信云开发

1. 打开微信开发者工具
2. 点击顶部「云开发」按钮
3. 进入云开发控制台
4. 左侧菜单「云函数」
5. 点击 `voice-recognize` 函数
6. 点击「环境变量」标签
7. 点击「添加」按钮，添加两个环境变量：

```
变量名：TENCENTCLOUD_SECRETID
变量值：[你的 SecretId]

变量名：TENCENTCLOUD_SECRETKEY
变量值：[你的 SecretKey]
```

8. 点击「保存」

### 步骤 4：上传云函数

1. 在微信开发者工具中
2. 右键 `cloudfunctions/voice-recognize` 文件夹
3. 选择「上传并部署：云端安装依赖」
4. 等待上传完成

## 🔒 安全说明

### 密钥存储位置

| 位置 | 是否安全 | 说明 |
|------|----------|------|
| 云函数环境变量 | ✅ 安全 | 推荐方式 |
| 前端代码 | ❌ 危险 | 绝对禁止 |
| Git 仓库 | ❌ 危险 | 绝对禁止 |
| 群里发送 | ❌ 危险 | 绝对禁止 |

### 密钥泄露处理

如果密钥泄露：

1. 立即登录腾讯云控制台
2. 访问管理 → 访问密钥
3. 禁用泄露的密钥
4. 新建密钥
5. 更新云函数环境变量

## 🔍 常见问题

### Q1: 提示"密钥无效"
```
原因：密钥配置错误或未生效
解决：
1. 检查环境变量是否拼写正确
2. 重新上传云函数
3. 等待 1-2 分钟生效
```

### Q2: 提示"权限不足"
```
原因：子账号没有语音识别权限
解决：
1. 主账号登录腾讯云
2. 访问管理 → 用户列表
3. 找到 shijitong 用户
4. 添加权限：QcloudASRFullAccess
```

### Q3: 识别失败
```
原因：音频格式或网络问题
解决：
1. 检查录音时长（<60 秒）
2. 检查网络状况
3. 查看云函数日志
```
