# 🎤 语音创建任务功能配置指南

**版本：** v1.0  
**更新时间：** 2026-03-24

## 📋 功能说明

### 实现功能
1. ✅ 语音录音（60 秒）
2. ✅ 腾讯云语音识别（ASR）
3. ✅ NLP 智能解析（时间/执行人/优先级/分类）
4. ✅ 自动回填表单
5. ✅ 支持连续语音输入

### 支持语音指令

**时间识别：**
- "今天" → 当天日期
- "明天" → 明天日期
- "后天" → 后天日期
- "周五" → 本周五日期
- "3 月 25 日" → 2026-03-25
- "下午 3 点" → 今天 15:00
- "10 天后" → 10 天后日期

**执行人识别：**
- "交给张三" → 执行人：张三
- "给李四" → 执行人：李四
- "让王五处理" → 执行人：王五

**优先级识别：**
- "紧急" → P0（紧急重要）
- "重要" → P1（重要）
- "一般" → P2（普通）

**重复任务：**
- "每天" → 每日重复
- "每周" → 每周重复
- "每月" → 每月重复

**分类识别：**
- "盛合智联" → 分类：盛合智联
- "龙耀辉科技" → 分类：龙耀辉科技
- "财务" → 分类：财务

## 🔧 配置步骤

### 步骤 1：开通腾讯云语音识别

1. 访问腾讯云官网：https://cloud.tencent.com/
2. 注册/登录账号
3. 进入控制台 → 搜索"语音识别"
4. 开通"语音识别 ASR"服务
5. 获取密钥：
   - SecretId
   - SecretKey

### 步骤 2：配置云函数环境变量

**在微信开发者工具中：**

1. 右键 `cloudfunctions/voice-recognize`
2. 选择"上传并部署：云端安装依赖"
3. 上传完成后，进入云开发控制台
4. 云函数 → voice-recognize → 环境变量
5. 添加以下环境变量：

```
TENCENTCLOUD_SECRETID=你的 SecretId
TENCENTCLOUD_SECRETKEY=你的 SecretKey
```

### 步骤 3：配置云函数权限

**在云开发控制台：**

1. 云函数 → voice-recognize → 权限配置
2. 确保有以下权限：
   - 云文件读写权限
   - 外网访问权限（调用腾讯云 API）

### 步骤 4：测试语音识别

**测试语音示例：**

```
"明天下午 3 点提交产品报告"
→ 任务名称：提交产品报告
→ 时间：2026-03-25
→ 优先级：P1（默认）

"紧急！今天交给张三处理财务报销"
→ 任务名称：处理财务报销
→ 时间：今天
→ 执行人：张三
→ 分类：财务
→ 优先级：P0

"每周五整理汇总销售数据，重要"
→ 任务名称：整理汇总销售数据
→ 时间：本周五
→ 优先级：P1
→ 重复：每周
```

## 📊 NLP 解析规则

### 时间解析规则

```javascript
// 正则表达式
/今天 | 明天 | 后天 | 周 [一二三四五六日天]|\d+ 月\d+ 日|\d+ 点 |\d+ 天后/

// 示例
"今天" → 2026-03-24
"明天" → 2026-03-25
"周五" → 2026-03-27
"3 月 25 日" → 2026-03-25
"下午 3 点" → 2026-03-24 15:00
"10 天后" → 2026-04-03
```

### 执行人解析规则

```javascript
// 正则表达式
/交给 | 给|让\s*(\w+)/

// 示例
"交给张三" → 张三
"给李四" → 李四
"让王五处理" → 王五
```

### 优先级解析规则

```javascript
// 正则表达式
/紧急 | 急件 | 加急 | 重要 | 重点 | 一般 | 普通 | 日常/

// 映射
紧急/急件/加急 → P0
重要/重点 → P1
一般/普通/日常 → P2
```

### 任务拆分规则

```javascript
// 按标点符号拆分
/[,.,,,,.]/

// 示例
"提交报告，整理数据，发送邮件"
→ 任务 1：提交报告
→ 任务 2：整理数据
→ 任务 3：发送邮件
```

## 🎤 使用流程

### 用户操作流程

```
1. 进入创建任务页面
2. 点击任务名称右侧 🎤 按钮
3. 开始录音（红色脉冲动画）
4. 说话："明天下午 3 点提交产品报告"
5. 再次点击 🎤 停止录音
6. 显示"识别中…" → "解析中…"
7. 弹窗显示识别结果
8. 点击"确认"
9. 表单自动填写完成
10. 检查无误后点击"创建任务"
```

### 系统处理流程

```
录音 → 上传云存储 → 云函数调用
  ↓
腾讯云 ASR 识别 → 返回文字
  ↓
NLP 智能解析 → 提取关键信息
  ↓
回填表单 → 用户确认
  ↓
创建任务 → 完成
```

## ⚠️ 注意事项

### 1. 密钥安全

**❌ 不要在前端代码中暴露密钥**
```javascript
// 错误做法
const SECRET_ID = 'xxx'  // 不要这样做！
```

**✅ 正确做法：云函数环境变量**
```javascript
// 正确做法
const SECRET_ID = process.env.TENCENTCLOUD_SECRETID
```

### 2. 录音权限

小程序需要录音权限，在 `app.json` 中配置：

```json
{
  "permission": {
    "scope.record": {
      "desc": "用于语音输入创建任务"
    }
  }
}
```

### 3. 语音时长

- 最长录音：60 秒
- 推荐时长：5-30 秒
- 过短可能识别不完整
- 过长可能超时

### 4. 识别准确率

**影响准确率的因素：**
- 环境噪音（安静环境最佳）
- 语速（适中最佳）
- 发音清晰度（普通话最佳）
- 网络状况（4G/WiFi 最佳）

**典型准确率：**
- 安静环境 + 普通话：95%+
- 嘈杂环境：80-90%
- 方言：70-80%

## 🔍 调试方法

### 查看日志

**云函数日志：**
```
云开发控制台 → 云函数 → voice-recognize → 日志
```

**关键日志：**


### 常见错误

**错误 1：密钥配置错误**
```
错误信息：Signature failure
解决：检查环境变量 SecretId/SecretKey 是否正确
```

**错误 2：音频文件过大**
```
错误信息：Invalid parameter
解决：限制录音时长在 60 秒内
```

**错误 3：网络超时**
```
错误信息：Timeout
解决：检查网络，重试
```
